- Built in KWGT to replace Spotify's default Android widget. Tapping a cover tile opens that album or playlist in Spotify without starting it, where the default widget starts playing straight away.
- The panel colour comes from Material You and the accent colour from the album art, and everything is set in JetBrains Mono Nerd Font. There's no progress bar and no Spotify branding. When nothing's playing, the last song stays on screen, dimmed.
- KWGT can't safely hold API credentials or handle Spotify's OAuth login, so I put a Cloudflare Worker in the middle. It keeps the refresh token in Workers KV, gets a new access token when the old one expires, and sends back one line of text with its fields separated by semicolons, which is easy to split in KWGT.
- The widget adds the current song's length and title to the feed URL. The URL changes every time the song does, so KWGT fetches fresh data instead of reusing its cached copy.

## Playlist covers

Playlists Spotify makes itself, like On Repeat, often don't return a cover through the API. The Worker works down a list of sources and caches whatever it finds in memory and in KV for a week.

- A cover I've uploaded through the Worker's covers page
- The Spotify Web API
- Spotify's oEmbed thumbnail
- The album art of the last song I played

## Clock

The clock's colon glows in the colour of the album art of whatever is playing, and underneath it shows the date, weather and air quality. KWGT doesn't provide air quality, so the clock asks the Worker for it once an hour with my location, and the Worker gets it from Open-Meteo, which doesn't need an API key.

## Setting it up

The repository has the steps for deploying your own Worker and importing both widgets into KWGT. It also has a script that builds a fake feed, so the widget can be tried for screenshots without a Spotify login.
